docker安装nexus


docker pull sonatype/nexus:pro-2.15.2

ps: 这个有的时候官方镜像可以拉取，有的时候又不可行，看来根网络环境有关系


mkdir /opt/nexus-data && chown -R 200 /opt/nexus-data


docker run -d -p 8081:8081 --name nexus -v /opt/nexus-data:/sonatype-work sonatype/nexus:pro-2.15.2


ps： 注意上面这个版本需要认证码，没有去折腾这个，所以还是用的以前的nexus来实现的
